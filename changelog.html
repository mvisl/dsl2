Release notes

What changed

Human-readable history of the design reference package. Use this page to understand what changed before giving the file to designers or AI agents.

Current1.1.1

Source-to-usage component workflow

Trace existing components through actual product contexts, then build the approved F2 system in Figma and the web.
Previous1.1.0

Review workflow and developer workspace

An F2-driven reference with traceable decisions, reusable screen recipes, and explicit verification gates.
Previous 1.0.8

UX Core became an agent rule

Agents now use applicable UX Core heuristics as a strong default for interface and flow decisions, while Design System sources, tokens, accessibility, compliance, and confirmed product behavior remain authoritative.

Figma rules 1.0.7

More exact Figma working rules

Added stricter source transfer, spacing, typography, icon, card, category, and verification guidance from the active Design System Figma workflow.

Previous 1.0.6

DSL rules became mandatory

The reference now explicitly requires design-system tokens, styles, spacing, radii, icons, and components for product UI, docs, review boards, and AI-generated artifacts.

Rules 1.0.5

Sharper AI-agent rules

The reference says more plainly how AI agents should work: transfer source values exactly, keep variable and style bindings, and mark only truly unavailable source nodes as DRAFT.

F2 rules 1.0.4

Expanded Facelift 2 coverage

Added clearer F2 guidance for airier dark surfaces, orange active states, matte-glass plates, rounded pills, Tabbar, Top Navigation, badges, and migration decisions.

Sources 1.0.3

Connected and offline usage paths

Added Figma MCP recommendations for teams with access, plus a compact offline fallback for agents that only receive this file.

Package 1.0.2

Added the online package

Added GitHub canonical links, a manifest for lightweight version checks, and the first downloadable black/orange page for the design reference.

Safety 1.0.1

Freshness checks for AI agents

Added rules that tell AI agents to check the canonical version once per day and warn clearly if the local file is stale.

Start 1.0.0

First compact design reference

Collected the first portable design rules for colors, type, spacing, component behavior, source guidance, and AI-agent usage.

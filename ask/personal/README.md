# Personal design conversations

Neutral optional UI at /dsl2/ask/personal/. Requires an owner-issued private invitation; no account registration or repository/constructor access. This package contains no invitation, grant, credentials or private records. Browser identity uses an origin-local non-exportable key; clearing site data requires replacement access. Server routes remain unavailable while GUEST_CONVERSATIONS_ENABLED is absent or 0. Publishing files does not enable access. Existing anonymous /ask/ and owner/auth55 pages stay separate.

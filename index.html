Release notes

What changed

Human-readable updates for designers and AI agents. Open the full log page for a clearer release history.

1.2.39

Stable geometry and independent previews

Preserve native dimensions under viewing zoom and keep relevant previews independent from unrelated source loading.

 1.2.38

Shared typography and scoped status roles

Preserve source-backed compact label appearance through shared typography and independent component roles.

 1.2.37

Keep status identity tied to context

Retain approved level colors and symbols without flattening distinct product contexts.

 1.2.36

Keep row data roles explicit

Map displayed values to their actual product context before reusing a row.

 1.2.35

Keep component color roles distinct

Use scoped color aliases while preserving state, artwork and native modes.

 1.2.34

Compose screens in their real context

Verify page composition, entry actions and the right presentation alongside traceable source components.

 1.2.31

Keep action roles and source versions distinct

Use the right corner role, preserve genuine variants and verify the actual source context.

 1.2.29

Keep shape and context meaningful

Match action edges, help spacing and workspace context to their actual roles.

 1.2.28

Keep collaboration in context

Preserve one thread, a stable draft and truthful delivery states.

 1.2.27

Keep help in the content flow

Place contextual help after the content it supports and verify real overflow.

 1.2.26

Verify fonts and optical clearance

Preserve actual font identity and review visible text relationships in context.

 1.2.25

Keep padding semantic

Preserve outer padding and inner clearance as separate layout responsibilities.

 1.2.24

Give rounded controls room

Preserve clear edges and match surfaces by semantic role.

 1.2.23

Fit values without hiding them

Use content-sized summaries and preserve genuinely joined controls.

 1.2.22

Preserve semantic radius roles

Resolve actual component bindings and modes before adapting rounded surfaces.

 1.2.21

Preserve measured edge controls

Keep native geometry and content separate from unverified scroll behavior.

 1.2.20

Keep useful filters active

An empty filtered result does not remove genuine choices or actions.

 1.2.19

Isolate repeated vector renders

Preserve source artwork when previews and canvases render together.

 1.2.18

Preserve component content

Keep donor content and consumer overrides intact during migration.

 1.2.17

Mobile components and draft recovery

Keep content editable, actions visible and drafts recoverable.

 1.2.16

Responsive media and portable source studies

Verify actual responsive hosts, preserve native media and font licenses, and distinguish inspection from supported composition.

 1.2.15

Measured native states and genuine component transfer

Measure actual optional-state layouts, verify current context and artwork, and preserve the native component graph across files.

 1.1.1

Source-to-usage component workflow

Trace existing components through actual product contexts, then build the approved F2 system in Figma and the web.

 1.1.0

Review workflow and developer workspace

An F2-driven reference with traceable decisions, reusable screen recipes, and explicit verification gates.

 1.0.8

UX Core became an agent rule

Added UX Core as a strong default for interface and flow decisions, with explicit safeguards against manipulative dark patterns.

1.0.7

More exact Figma working rules

Added stricter source, spacing, typography, icon, card, category, and verification rules from the active Figma workflow.

1.0.6

DSL rules became mandatory

Locked the rule that design references, review pages, and AI outputs must use Design System tokens, styles, spacing, radii, and components instead of invented values.

1.0.5

Sharper AI-agent rules

Added stricter guidance for exact source transfer, no invented values, token/style binding, and clear DRAFT labeling when a source node is unavailable.

1.0.4

Expanded Facelift 2 coverage

Documented the F2 direction for airier dark surfaces, orange active states, glass plates, Tabbar, Top Navigation, badges, and migration decisions.

1.0.3

Added source links and fallbacks

Added Figma source references, connected-mode recommendations, offline fallback tokens, and once-per-day freshness checks.

1.0.2

Online package added

Added the downloadable package, canonical links, a lightweight version manifest, and a first public landing page.

1.0.1

Freshness checks

Taught agents to verify the canonical version once per day and warn clearly when a local file is stale.

1.0.0

First usable draft

Collected the first compact rules for colors, typography, components, Figma sources, and AI-agent usage.
